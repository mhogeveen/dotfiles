# archived desktop designs

Versions of designs kept for reference; nothing here is compiled (only `src/`
is). To bring one back, copy it to `src/desktop/`, add a `Design` variant,
name and line in `desktop::page` (see `docs/subsystems.md` 5.6).

- `ridges-original.rs`, `ridges-original.png`: ridges as first built
  (2026-11-16), every stroke running to the bottom of the page. Liked as it
  was; replaced only because stacked soft stroke edges showed as slivers in
  the gaps of the nearest hills (item 44).
